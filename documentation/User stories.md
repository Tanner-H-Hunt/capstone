User stories

\# while logged out:

\[ ] User can press the login button to be brought to the login screen

\[ ] User can press the create account button to be brought to the create account screen



\## on the login screen

\[ ] The user can press a link to the create account page

\[ ] The user may press a button to cancel their login and be brought to the logged-out homepage

\[ ] If the user enters an incorrect username / password combination, they are notified of their error

\[ ] The user is notified if they've entered a blank email or password

\[ ] The user is brought to the home page if they enter a valid email/password combination



\## on the account creation screen

\[ ] The user may press a button to login if they already have an account

\[ ] The user may press a button to return to the logged-out homescreen to cancel account creation

\[ ] The user is notified if they've entered a blank email or password

\[ ] The user is notified if they've entered an incorrect email/ password combination

\[ ] The user is logged in if they create an account and are brought to the logged-in homepage





\# while logged in:



\## On the home screen

\[ ] The user may press a button to log out of their account and is brought back to the logged-out homepage

\[ ] The user can view a list of their created document

\[ ] The user can filter their documents by type

\[ ] The user can filter their documents by name

\[ ] The user can create a new document by type

\[ ] Before a new document is created, the user is prompted to name the document

\[ ] Once a new document is created, the user is immediately navigated to the new document

\[ ] The user can delete a document

\[ ] The user can edit the name of a document



\## On the edit diagram page

\[ ] On entering the document page, the user sees the previously saved state of the document

\[ ] The user can navigate to the home page

\[ ] The user can log out and is brought to the logged-out homepage

\[ ] The user can click and drag the right mouse button to translate the camera

\[ ] The user can use the scroll wheel to zoom the camera in and out

\[ ] The user can drag and drop an element to add it to the screen

\[ ] The user can select an element on the screen to edit, including changing its position and size

\[ ] The user can delete a selected element

\[ ] When the user selects an element, a sidebar containing its relationships appears

\[ ] The user can create a new relationship on a ticket with an existing document

\[ ] The user can create a new relationship on a ticket with a new document and is navigated to the newly created document

\[ ] The user can delete a relationship with the selected note

\[ ] Changes to the diagram are automatically saved when the user navigates away from the page

\[ ] Changes to the diagram are automatically saved on a regular interval

\[ ] The user is notified that their document is auto saved if they press an auto-save shortcut (ctrl-s)



\## On the edit notes page

\[ ] On entering the document page, the user sees the previously saved state of the document

\[ ] The user can navigate to the home page

\[ ] The user can log out and is brought to the logged-out homepage

\[ ] The user can edit the text content of the notes page

\[ ] The user can see documents that are related to this one

\[ ] The user can create a new relationship with an existing document

\[ ] The user can create a new relationship with a new document and is navigated to the newly created document

\[ ] The user can delete a relationship

\[ ] Changes to the notes are automatically saved when the user navigates away from the page

\[ ] Changes to the notes are automatically saved on a regular interval

\[ ] The user is notified that their document is auto saved if they press an auto-save shortcut (ctrl-s)



\## On the edit todo page

\[ ] On entering the document page, the user sees the previously saved state of the document

\[ ] The user can navigate to the home page

\[ ] The user can log out and is brought to to the logged-out homepage

\[ ] The user can click and drag the right mouse button to translate the camera

\[ ] The user can use the scroll wheel to zoom the camera in and out

\[ ] The user can create a new ticket

\[ ] The user can delete a ticket

\[ ] The user can give a ticket a title

\[ ] The user can give a ticket a description

\[ ] The user can drag and drop a ticket between three swimlanes

\[ ] When the user selects a ticket, a sidebar containing its relationships appears

\[ ] The user can create a new relationship on a ticket with an existing document

\[ ] The user can create a new relationship on a ticket with a new document and is navigated to the newly created document

\[ ] The user can delete a relationship with the selected note

\[ ] Changes to the todo are automatically saved when the user navigates away from the page

\[ ] Changes to the todo are automatically saved on a regular interval

\[ ] The user is notified that their document is auto saved if they press an auto-save shortcut (ctrl-s)
